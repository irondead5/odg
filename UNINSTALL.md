# How to Uninstall Open Docs Gen (`odg`)

This guide provides step-by-step instructions for a developer or an AI Agent / LLM to completely uninstall `odg` (`open-docs-gen`) from the system and any repositories where it was initialized.

---

## 1. Global Terminal CLI Uninstallation

To remove the global `odg` and `open-docs-gen` binary commands from your machine:

```bash
# If installed via npm link / npm install -g:
npm unlink -g open-docs-gen

# Or if installed globally via pnpm:
pnpm remove --global open-docs-gen
```

Verify that the command was removed:
```bash
which odg
# Should return nothing or "odg not found"
```

---

## 2. Global Antigravity CLI (`agy`) Uninstallation

To remove the global `/odg` workflow and `odg` skill from Antigravity:

```bash
# Remove global skill and workflow
rm -rf ~/.gemini/config/skills/odg
rm -f ~/.gemini/config/workflows/odg.md
```

If a global plugin was installed in `~/.gemini/config/plugins/`:
```bash
rm -rf ~/.gemini/config/plugins/odg
```

---

## 3. Repository-Level Uninstallation (Clean Up a Project)

If `odg init` was run in a repository, remove the generated configuration, cache, and tool integration files:

### Step 3.1: Remove ODG Core Directory
```bash
# Removes settings, manifest, and cached DuckDB database
rm -rf .odg
```

### Step 3.2: Remove AI Tool Commands & Skills Generated by ODG
```bash
# Antigravity CLI / IDE integrations
rm -f .agents/workflows/odg*.md
rm -rf .agents/skills/odg
rm -rf .agents/plugins/odg

# Claude Code integrations
rm -rf .claude/commands/odg
rm -rf .claude/skills/odg

# GitHub Copilot integrations
rm -f .github/prompts/odg*.prompt.md
rm -rf .github/skills/odg

# Codex CLI integrations
rm -f .codex/prompts/odg*.md
rm -rf .codex/skills/odg

# Gemini CLI integrations
rm -rf .gemini/commands/odg
rm -rf .gemini/skills/odg

# Cursor & Windsurf integrations
rm -f .cursor/commands/odg*.md
rm -f .cursor/rules/odg.mdc
rm -f .windsurf/workflows/odg*.md
```

### Step 3.3 (Optional): Remove Generated Documentation Artifacts
If you also want to delete the Markdown and diagrams generated by `odg`:
```bash
rm -rf .odg/human
rm -rf .odg/ai
```
*(If you want to keep the generated documentation for your team, leave the markdown files intact and only delete `.odg/cache/`)*.
